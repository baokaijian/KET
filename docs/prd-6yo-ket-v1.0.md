## 0. 阅读指南

本文档分两大部分：

- **第 1 章为现状盘点**。所有数字来自仓库实际文件与可执行统计，用于回答"我们现在手里有什么"。
- **第 2–11 章为产品需求**。用于回答"面向 6 岁儿童，应该做成什么样"。

凡标注"现状"的内容是可核验的既有事实；凡标注"目标"的内容是本版本要新建的需求；凡标注"缺口"的内容是当前实现与目标之间的差距，需排期补齐。

**本 PRD 的核心判断：内容储备已经过剩，交互层严重不足。**

平台已有 1687 个 KET 词、1867 道题、48 个儿童活动、24 节语法课——内容量足以支撑 2 年学习。但这些内容目前被包裹在一套**以中文文字为主的成人化界面**里：导航是"今天 / 学习天地 / KET 小测 / 成长记录"，任务卡有 20–40 字的中文说明，练习页出现"首次答对 8 / 10 题""订正不改变首次得分"这类句子。一个识字量约 300 字的一年级孩子无法独立读懂这些。

因此 v2.0 不需要再造内容，需要造**一层"零识字可用"的交互外壳**，以及**一套能把家长变成合格陪练的编排系统**。

## 1. 现状盘点

### 1.1 技术基础

| 维度 | 实际情况 | 对 6 岁场景的意义 |
| :--- | :--- | :--- |

| 路由 | hash 路由（`#today` / `#learn` / `#assessment` / `#progress`） | 静态部署刷新不 404，适合 GitHub Pages |

| 触控 | 全局 `button { min-width: 44px; min-height: 44px }` | 达到无障碍底线，但**未达 6 岁适用标准（需 ≥64px）** |

### 1.4 学习机制现状

| 机制 | 现有实现 | 参数 |
| :--- | :--- | :--- |
| 每日排课 | `buildDailyPlan` 依据到期量、未来 7 天预测负荷、星期几动态生成 | 新词 8 / 4 / 2 三档；复习每批 10 题、每日上限 30 题 |
| 间隔复习 | 独立答对后按固定序列推后 | 1 / 2 / 4 / 7 / 16 / 30 / 60 / 120 / 180 / 365 天 |
| 防重复 | 同一技能需跨日且间隔 ≥4 小时才能推进 | 跨午夜几分钟不算两个学习日 |
| 掌握判定 | 听、读**分别**记录，各需 ≥3 个不同日期独立答对 | 提示后答对不计独立掌握 |
| 错题处理 | 每题可"再试一次"一次，订正不改首次得分 | 订正后仍进次日复习 |
| 断点续学 | 活动快照存入 `localStorage`，含指纹校验 | 退出/刷新可续 |
| 周末策略 | 周六只排故事；周日轻量复习，不排新词 | 防止 6 岁负荷过载 |
| 同步 | Supabase 账户 + 合并规则 + 离线队列 | 录音永不上传 |

这套机制的教学严谨度**高于多数同类儿童 App**，是产品的核心资产，v2.0 必须原样保留，只改变它的"表达方式"。

### 1.5 关键缺口（本次要解决的真问题）

| # | 缺口 | 证据 | 影响 |
| :-- | :--- | :--- | :--- |
| G1 | **无自学/陪学模式概念** | 全局搜索无 `mode='solo'/'colearn'`，`App` 只有页面切换 | 家长不知道"该不该坐在旁边"，孩子独学时无人兜底 |
| G2 | **儿童端文字过载** | 今日任务卡含"复习间隔还没到，先听读今天的内容"等长句；练习页有"订正不改变首次得分" | 6 岁无法独立理解，必须成人翻译 |
| G3 | **导航依赖识字** | 顶栏四个中文标签，无图标语音说明 | 孩子找不到入口，首次使用必然求助 |
| G4 | **无家长中心** | `ParentDashboard` 已在早前版本删除，家长只能看儿童同款"成长记录" | 家长无法回答"他到底学会了什么、我该做什么" |
| G5 | **图片覆盖 6.8%** | 115/1687 | 无图词无法做"图—词"直连，违背零识字原则 |
| G6 | **无语音指令层** | 只有单词/句子朗读，"点这里开始"没有音频 | 读不懂就卡死 |
| G7 | **触控尺寸偏小** | 全局 44px | 6 岁手指精细动作未发育完全，误触率高 |
| G8 | **文案能力断言过度** | "KET 小测""本课已通过" | 6 岁家长易误解为官方备考，产生错误预期 |

## 2. 产品定位与目标用户

### 2.1 一句话定位

> **给 6 岁孩子的第一套"不用认字也能学"的英语启蒙系统：孩子自己点得动，家长坐下就能陪。**

### 2.2 目标用户

| 角色 | 画像 | 核心诉求 | 使用场景 |
| :--- | :--- | :--- | :--- |
| **主用户：孩子（5–7 岁，一年级）** | 识字量 200–400 字；能听懂中文指令；会点、拖、滑；注意力 5–10 分钟；不能盲打、不会拼写 | "我能自己玩明白""不要被批评" | 放学后 10–20 分钟；周末早上 |
| **决策者/陪练：家长（30–40 岁）** | 英语基础参差，发音不自信；碎片时间；不懂 CEFR | "知道今天该干什么""知道孩子哪里不会""我该说什么话" | 晚上陪坐 10 分钟；通勤时看进度 |
| **次要：祖辈/保姆** | 完全不懂英语 | "按一下就能开始，别让我选" | 父母不在时的替代陪护 |
| **非用户：教师/机构** | — | 本版本不服务 | — |

### 2.3 明确不做（Non-Goals）

1. **不做 KET 模考与分数预测**。平台不提供剑桥成绩预估，不出现"你能考 120 分"。
2. **不做 AI 发音评分**。当前无可靠儿童语音评测链路，避免给出错误反馈伤害自信。
3. **不做社交、排行榜、班级、PK**。6 岁不适用横向比较。
4. **不做直播课/真人外教**。
5. **不做内容开放编辑**（家长不能自建词表，避免破坏分级）。
6. **不做广告与内购**。

### 2.4 核心价值主张

| 主张 | 支撑 | 与同类差异 |
| :--- | :--- | :--- |
| 零识字可用 | 图标 + 语音 + 单主动作 + 图词直连 | 多数 App 仍需家长读题 |
| 真·间隔复习 | 跨日、分技能、3 日判定掌握 | 多数 App 只做"答对即过" |
| 陪学有剧本 | 家长台词卡 + 介入记录 + 渐进撤除 | 多数 App 把"家长模式"做成设置页 |
| 不制造挫败 | 无红叉、无倒计时、无排名、错题可再试 | 多数 App 用星级/连击施压 |
| 内容不虚标 | 明确"不是官方模考"，图片不冒充 | 多数 App 暗示"保过" |

### 2.5 指标定义

| 类型 | 指标 | 定义 | v2.0 目标 |
| :--- | :--- | :--- | :--- |
| 北极星 | **周独立完成率** | 一周内无需成人介入完成 ≥3 次完整"今日任务"的孩子占比 | ≥ 60% |
| 健康度 | 单次时长 | 一次会话的中位时长 | 8–14 分钟（不追求越长越好） |
| 健康度 | 次日回访率 | 今天学过、次日再打开的比例 | ≥ 55% |
| 健康度 | 陪学转自学率 | 陪学 4 周后转自学的家庭占比 | ≥ 30% |
| 内容 | 图词覆盖 | L0–L2 全部词的已核验图片比例 | 100% |
| 体验 | 首次独立开始率 | 首次使用 60 秒内自己点进第一个任务的占比 | ≥ 90% |

## 3. 设计原则：零识字可用（Zero-Literacy Usable）

这是本产品的**第一性原则**，所有界面决策冲突时以此裁决。

### 3.1 五条原则与可检验规则

| # | 原则 | 可检验规则 |
| :-- | :--- | :--- |
| P1 | **能听就不读** | 儿童端每一处文字（含按钮、提示、标题）都必须有语音等价物；点击文字块即可朗读 |
| P2 | **一屏一事一动作** | 每个儿童端页面只有 1 个主按钮；主按钮面积 ≥ 屏宽 70%，高度 ≥ 72px |
| P3 | **图标先行，文字可藏** | 所有导航与任务用图标 + 大色块表意；文字为辅助，可在"家长设置"中完全隐藏 |
| P4 | **不制造失败** | 无红叉、无"错了"、无倒计时、无分数排名；错误表述统一为"再听一次" |
| P5 | **手能够到** | 所有可点元素 ≥ 64×64px，间距 ≥ 12px；主要操作位于屏幕下 1/3（儿童持握区） |

### 3.2 儿童端字数量化上限

| 位置 | 上限 | 说明 |
| :--- | ---: | :--- |
| 单屏可见汉字（导航 + 提示 + 按钮） | ≤ 12 字 | 不含正在学习的英文单词/句子 |
| 单条语音提示 | ≤ 15 秒，≤ 2 句 | 中文 1 句 + 英文目标句 1 句 |
| 任务卡标题 | ≤ 4 字 | 如"复习""新词""听句""故事" |
| 结果页 | ≤ 8 字 | 如"完成啦！" |

### 3.3 "遮字测试"（验收手段）

> 把儿童端所有中文文字遮住，仅保留图标、图片与语音，一名 6 岁儿童应能独立完成"首页 → 新词 → 答题 → 返回"全流程。

该测试是本 PRD 的核心验收方法，见 9.3。

### 4.2 M1 今日任务（首页）

**目标：** 孩子打开就能开始，不需要做任何选择。

**用户故事**
- 作为孩子，我打开应用就看到一张大卡片，点一下就开始学，不用读字。
- 作为家长，我一眼看出今天大概要花多久、学什么。

**关键交互**

1. 启动后 1.5 秒内自动语音播报（可关闭）："今天我们认识 4 个新朋友。"——**仅首次进入播报，不反复打扰**。
2. 首页只呈现**一张"现在做这个"主卡**（下一件未完成任务），配大图 + 图标 + 4 字标题 + 播放按钮。
3. 其余任务折叠为底部 4 个小圆点，用颜色与图标区分（灰=未开始，黄=进行中，绿=已完成），点小圆点可切换。
4. 主卡下方一个"耳朵"按钮，重听本步指令。
5. 无文字导航；左上角"房子"图标 = 回首页，右下角"星星"图标 = 去图鉴。

**数据依赖：** `buildDailyPlan`（保留）、`reviewBatch`（保留）、`dailyVocabularyLesson`（保留）。

**验收：** 6 岁儿童首次使用，未经提示在 60 秒内点进第一个任务（≥90% 成功率，样本 ≥5 人）。

### 4.3 M2 词汇（图词卡）

**目标：** 建立"图—音—义"直连，不要求拼写、不要求认字。

**卡片规格（强制）**

| 元素 | 规格 |
| :--- | :--- |
| 图片 | 占屏 ≥55%，圆角 24px，统一构图（主体居中、无文字、无遮挡） |
| 英文词 | 48–64px，圆润字体；可点读 |
| 中文义 | ≤6 字，24px，浅色；**默认隐藏**，点"眼睛"图标或听语音后出现 |
| 音标 | 默认隐藏（6 岁无意义），家长模式可见 |
| 主按钮 | "听一听"（喇叭图标 + 播放动效） |
| 次按钮 | 左"上一个"右"下一个"，圆形 ≥64px |

**交互流程**

```
图词卡（自动读 1 次）
   ↓ 孩子点"听一听"
慢速再读 1 次 + 单词高亮逐字母跳动
   ↓ 孩子点"下一个"或滑动
下一张卡
   ↓ 全部看完
自动进入"找一找"（3 选 1 图）
```

**降级策略（关键）**
- 3 选 1 答错 → 保留原题，把正确图片**轻微放大发光**（不指出答案）。
- 再错 → 只剩 2 选 1，并朗读目标词。
- 第三次 → 直接展示正确项 + 朗读，标记 `needsReview`，**不记为错误**。

**验收：** 全部 L0/L1 词具备已核验图片；无图词不得进入儿童端（当前 1572 词被阻断，见 G5）。

---

### 4.4 M3 听读（句子 / 故事 / 长文）

**目标：** 从"听懂一句"到"读懂一篇"，全程可点读。

**分层呈现**

| 层级 | 材料 | 交互 | 题量 |
| :--- | :--- | :--- | ---: |
| S1 句子 | 6 句 / 主题（现有 `childThemes.sentences`） | 点句听读 → 图片配对 | 6 |
| S2 短故事 | 30–60 词（现有 `story`） | 逐句高亮跟读 → 3 题理解 | 3 |
| S3 进阶故事 | 103–113 词（现有 `longStory`） | 整篇朗读 + 点词查义 → 4 题 | 4 |
| S4 长文 | 155–245 词（现有 `long-passages`） | 分段读 + 路标词高亮 → 主旨/细节/推断 | 3–5 |

**儿童端规则**
- 阅读页默认**不显示中文全文翻译**，只显示"点词看义"浮层（避免整段中文替代阅读）。
- 每个英文句子右侧有 1 个喇叭；整篇顶部有"慢速全文"。
- 读完一句有轻微"叮"与光点推进，形成节奏感。
- 一页最多 3 句，超过自动分页，避免长滚动。

**验收：** S2 及以下，儿童可全程不读中文提示完成；点词响应 < 100ms。

### 4.5 M4 练习与测评

**目标：** 提供反馈，而不是评判。

**题型白名单（儿童端）**

| 允许 | 禁止 |
| :--- | :--- |
| 听音选图 | 键盘拼写 |
| 看图选词 | 填空打字 |
| 句子配图 | 长句翻译 |
| 三选一理解 | 计时答题 |
| 拖拽排序（字母/情节） | 负数反馈语 |

拼写、填空、写作、语法讲解**全部收进"家长与进阶课程"折叠区**（现有实现已具备该折叠结构，只需把默认收起）。

**反馈语规范**

| 情形 | 文案 | 语音 |
| :--- | :--- | :--- |
| 答对 | "找到啦！" | 欢快短音 + "Great!" |
| 答错（第一次） | "再听一次。" | 柔和提示音，不播放"错误"音效 |
| 连续两次错 | "我们一起看。" → 展示答案 + 朗读 | 平静语气 |
| 完成 | "完成啦！" | 3 秒庆祝动效 + 贴纸掉落 |

> 现状问题：`playIncorrectSound()` 会播放负向音效，且结果页出现"首次答对 X / Y 题"。v2.0 儿童端必须替换为上述规范；家长端可保留精确数据。

### 4.7 M6 家长中心（新建）

**目标：** 家长在 3 分钟内回答三个问题：今天学了什么？他哪里卡住？我该做什么？

**信息架构**

| 区块 | 内容 | 更新时机 |
| :--- | :--- | :--- |
| ① 今日简报 | 学习时长、完成任务数、新词数、复习正确率 | 实时 |
| ② 本周曲线 | 7 天学习分钟数 + 独立完成率（双轴） | 每日 |
| ③ 掌握地图 | 12 主题 × 掌握词数（热力格） | 实时 |
| ④ 卡点清单 | 近 7 天错 ≥2 次的词/题，按主题聚合，可一键"今晚陪他看这 5 个" | 每日 |
| ⑤ 陪学建议 | 基于卡点生成 3 条具体动作（见 5.3 台词卡） | 每日 |
| ⑥ 时间与内容设置 | 每日时长上限、口音、语速、是否隐藏中文、是否锁定进阶区 | 手动 |
| ⑦ 数据与隐私 | 同步状态、导出记录、清除数据、录音说明 | 手动 |

**交互要求**
- 家长端**允许文字**，但必须用"结论 + 证据 + 动作"三段式，不堆原始数据。
- 所有图表提供一句话解读（例："周三之后中断了 3 天，建议把每日时长从 20 分钟降到 10 分钟"）。
- 进入方式：首页右上角"家长"图标 → 4 位 PIN（可选）→ 家长中心。**PIN 用于防止孩子误入，不是安全边界**。

**验收：** 5 名家长在无指导下，3 分钟内能说出"孩子这周学了几个词、最弱的主题是什么、今晚该做什么"（≥80% 达成）。

## 5. 自学 / 陪学双模式设计

### 5.1 模式定义

| | 自学模式（Solo） | 陪学模式（Co-learn） |
| :--- | :--- | :--- |
| 一句话 | 孩子独立操作系统完成学习 | 家长按剧本陪坐，逐步撤出 |
| 成人角色 | 不在场（或仅在场不介入） | 引导者、共读者、鼓励者 |
| 系统角色 | 替代老师：发指令、纠错、降难度 | 替代教研：给家长台词与节奏 |
| 适用 | 已能独立操作、家长时间碎片化 | 首次使用、注意力弱、需情绪支持 |
| 典型时长 | 8–12 分钟 | 10–15 分钟（含开场与收尾） |

### 5.2 模式选择与切换

**入口（首次使用）**

```
┌──────────────────────────────────┐
│         [ 小恐龙挥手动画 ]        │
│                                  │
│   ┌────────────┐ ┌────────────┐  │
│   │  🧒         │ │  👨‍👦        │  │
│   │  我自己学    │ │  一起学     │  │
│   └────────────┘ └────────────┘  │
│         🔊 听一听（语音说明两者区别）│
└──────────────────────────────────┘
```

- 语音说明："自己学，小恐龙会告诉你每一步。一起学，爸爸妈妈会拿到小提示。"
- 选择结果写入 `profile.modePreference`，**下次直接进入，不再询问**。
- 切换入口：首页长按"房子"图标 2 秒，或家长中心第一项。**孩子端不出现切换按钮**，避免误触打乱节奏。

**自动建议切换（关键机制）**

| 触发条件 | 建议 |
| :--- | :--- |
| 陪学模式下，连续 3 次会话家长介入 = 0 | 提示家长："他今天完全自己完成了，要不要试试自学模式？" |
| 自学模式下，单次会话中断 ≥3 次或连续 2 天未完成 | 提示家长："可能有点难，试试陪他 10 分钟？" |
| 孩子连续 2 次在首页停留 > 45 秒无操作 | 自动语音引导："点下面的大按钮。"（不切换模式） |

> 这是产品的差异化设计：**陪学不是永久状态，而是可退出的脚手架**。

### 5.3 自学模式详设

**流程（单次会话）**

```
① 启动
   └ 语音："今天我们认识 4 个新朋友。"（1 次，可跳过）
② 首页主卡
   └ 显示"现在做这个" + 大按钮
③ 任务内循环 ×N
   ├ 听指令（自动 + 可重听）
   ├ 看/听材料
   ├ 做 1 个动作（点/选/拖）
   ├ 反馈（正向音效 + 1 句鼓励）
   └ 进度点前进 1 格
④ 任务完成
   └ 庆祝 3 秒 + 贴纸掉落 + 返回首页
⑤ 会话结束
   └ 完成 2 个任务后，Mascot 主动说："要不要休息一下？"
```

**界面规范**

```
┌─────────────────────────────┐
│  🏠              🔊     ⭐  │  ← 仅图标，64px
├─────────────────────────────┤
│                             │
│      ┌───────────────┐      │
│      │               │      │
│      │   图片/题干    │      │  ← 占屏 ≥50%
│      │               │      │
│      └───────────────┘      │
│                             │
│      ● ● ○ ○                │  ← 进度点，20px
│                             │
│  ┌───────────────────────┐  │
│  │     ▶  开 始          │  │  ← 主按钮，h≥72px
│  └───────────────────────┘  │
│         🔊 听提示            │
└─────────────────────────────┘
```

**引导策略（系统即老师）**

| 时机 | 系统行为 | 语音内容 |
| :--- | :--- | :--- |
| 进入任务 | 自动播报 1 次 | "看图，听一听这个词。" |
| 10 秒无操作 | 图标脉冲 + 重播 | "点下面的大按钮。" |
| 答错 | 不批评，重播题干 | "再听一次。" |
| 连错 2 次 | 自动降难度（3 选 1 → 2 选 1） | "我们一起看。" |
| 完成 | 正向反馈 | "完成啦！你收集了一个新词。" |

**容错与退出**
- 任意时刻点"🏠"返回首页，进度自动保存（沿用 `practiceSession` 快照）。
- 不设"确认退出"弹窗（6 岁会被困住），改为**退出后首页恢复同一位置**。

### 5.4 陪学模式详设

**流程（单次会话）**

```
① 家长开场卡（仅家长可见，30 秒）
   └ "今天 10 分钟，重点是 4 个水果词。你不需要会英语。"
   └ [ 开始 ]  [ 换一个更简单的 ]
② 儿童区开始（屏幕 70%）
   └ 家长提示条常驻（屏幕下方 30%，可折叠）
③ 每环节家长有三件套
   ├ 目标：这一步要达成什么
   ├ 你可以说：2 句现成中文台词
   └ 你可以做：1 个肢体动作
④ 系统在关键点提示家长
   └ "现在轮到他了，先别说话，等 5 秒。"
⑤ 收尾卡（2 分钟）
   ├ 今天可以夸他的一句话
   ├ 今天发现的 1 个卡点
   └ 明天建议（1 条，不做清单）
```

**界面规范（手机竖屏）**

```
┌─────────────────────────────┐
│  👨‍👦 一起学          ⏸   ⚙️   │
├─────────────────────────────┤
│                             │
│      儿童区（同自学）        │
│      ┌───────────────┐      │
│      │     🍎        │      │
│      └───────────────┘      │
│      ● ● ○ ○                │
│  ┌───────────────────────┐  │
│  │     ▶  开 始          │  │
│  └───────────────────────┘  │
├─────────────────────────────┤
│ 家长提示 ▾                   │
│ 目标：听懂 apple / banana    │
│ 你说："你听到的是苹果吗？"   │
│ 你做：指一指图片             │
└─────────────────────────────┘
```

**界面规范（平板横屏）**

```
┌───────────────────────┬──────────────┐
│                       │  家长提示     │
│     儿童区（70%）      │  ─────────   │
│                       │  目标 …       │
│                       │  你说 …       │
│                       │  你做 …       │
│                       │  [ 下一步 ]   │
└───────────────────────┴──────────────┘
```

**家长台词卡（示例，L1「水果」环节）**

| 环节 | 目标 | 你可以说 | 你可以做 | 注意 |
| :--- | :--- | :--- | :--- | :--- |
| 看图听词 | 建立图—音连接 | "听听看，这是什么？" | 手指图片 | 不要先说出中文 |
| 跟读 | 敢于开口 | "我们一起说一遍。" | 夸张口型 | 不纠正发音细节 |
| 三选一 | 听辨 | "你听到的是哪一个？" | 手掌摊开示意 | 答错不抢答，等 5 秒 |
| 收尾 | 情绪闭环 | "今天你自己找到了 4 个。" | 击掌 | 只夸具体行为 |

**家长权限（仅陪学模式可见）**

| 权限 | 位置 | 说明 |
| :--- | :--- | :--- |
| 暂停 / 继续 | 顶栏 ⏸ | 暂停时不中断计时，仅冻结界面 |
| 跳过本环节 | 提示条底部 | 记录 `skipped`，不计入掌握 |
| 降低难度 | 提示条底部 | 3 选 1 → 2 选 1，本环节生效 |
| 看答案 | 长按题目 2 秒 | 仅家长可见，用于救场 |
| 结束会话 | 顶栏 ⚙️ | 生成收尾卡 |

### 5.5 差异对照表（核心交付物）

| 维度 | 自学模式 | 陪学模式 |
| :--- | :--- | :--- |
| **入口** | 首页两个大按钮之一，选择后不再询问 | 同上；家长先看 30 秒开场卡 |
| **身份识别** | 无 | 家长 PIN（可选）+ 孩子档案 |
| **流程长度** | 3 步：首页 → 任务 → 完成 | 5 步：开场卡 → 任务 → 环节提示 → 收尾卡 → 建议 |
| **界面布局** | 全屏儿童区 | 儿童区 70% + 家长提示条 30%（平板左右分栏） |
| **文字量** | 单屏 ≤12 汉字，默认隐藏中文义 | 儿童区同上；家长区不限，但用三段式 |
| **语音策略** | 语音 = 指令源，自动播报 | 语音 = 提示源，语速更慢，句间停顿 ≥1s |
| **Mascot 角色** | 老师：发指令、纠错 | 伙伴：只鼓励，不发指令（指令交给家长） |
| **错误处理** | 系统自动降难度 | 系统提示家长"等 5 秒"，家长接话；两次后系统兜底 |
| **反馈语** | "再听一次。" | "没关系，我们看看这个。"（由家长说，系统给句式） |
| **奖励** | 即时：音效 + 贴纸掉落 | 延迟：收尾卡统一给"今天收集了 X 个" |
| **单次时长** | 8–12 分钟，系统建议休息 | 10–15 分钟，家长控制节奏 |
| **中断恢复** | 静默恢复上次位置 | 恢复时先给家长 1 句"上次停在这里" |
| **数据记录** | `mode='solo'`，记录独立完成 | `mode='colearn'`，额外记录 `interventions`、`parentPromptsShown` |
| **退出** | 点 🏠 直接退，进度保存 | 走收尾卡，生成家长小结 |
| **权限** | 无 | 暂停/跳过/降难度/看答案/结束 |
| **成功标准** | 独立完成率 | 家长介入次数下降 + 孩子主动开口次数 |

### 5.6 关键场景走查

| 场景 | 自学模式 | 陪学模式 |
| :--- | :--- | :--- |
| **首次使用** | 语音引导点大按钮；首任务固定为最简单的"看图听词" | 家长开场卡说明"你不需要会英语"；首任务同上 |
| **孩子卡住 10 秒** | 按钮脉冲 + 语音"点这里" | 系统提示家长："可以指一下按钮。" |
| **答错** | 柔和音 + 重播题干，选项不变 | 系统提示 "先别说话，等 5 秒"；家长按台词回应 |
| **连续答错** | 自动 3 选 1 → 2 选 1 → 展示答案 | 家长可点"降低难度"；系统同步兜底 |
| **孩子分心离开** | 90 秒无操作后暂停音频，保留进度 | 家长可暂停，收尾卡记录"本次 6 分钟" |
| **家长不懂英语** | 不涉及 | 台词卡全中文，英文只出现在"你可以跟着读"的可选行 |
| **家长过度干预** | 不涉及 | 连续 3 次点击"看答案"，系统提示"让他自己试一次" |
| **结束** | 贴纸 + 返回首页 | 收尾卡：夸一句 + 1 个卡点 + 明天 1 条建议 |

## 6. 儿童友好与家长端交互要求

### 6.1 儿童端交互规范（硬性）

| 类别 | 规范 | 现状 |
| :--- | :--- | :--- |
| 触控目标 | ≥64×64px，间距 ≥12px | 44px，**需改** |
| 主按钮 | 高度 ≥72px，宽度 ≥70% 屏宽，圆角 ≥20px | 部分达标 |
| 字体 | 英文标题 ≥48px；中文 ≥24px；行高 ≥1.6 | 英文 30px，**需改** |
| 颜色 | 主色 ≤3 种；对比度 ≥4.5:1；不用纯红表错误 | 绿色主调，基本达标 |
| 动效 | ≤400ms；无闪烁、无抖动；提供"减少动效"开关 | 部分达标 |
| 音效 | 正向音效 ≤1s；**取消负向"错误"音效** | 有负向音效，**需改** |

| 加载 | 骨架屏 ≤1s；图片懒加载 + 模糊占位 | 部分达标 |
| 离线 | 断网可完成已缓存任务；提示用图标而非报错文字 | 支持，提示为文字 |
| 无障碍 | 全部图标有 `aria-label`；键盘可达；`prefers-reduced-motion` 生效 | 基本达标 |

### 6.2 文案规范

### 8.1 学习事件模型

### 8.2 掌握度算法（沿用，不修改）

| 规则 | 参数 |
| :--- | :--- |
| 复习间隔 | 1 / 2 / 4 / 7 / 16 / 30 / 60 / 120 / 180 / 365 天 |
| 最小跨日间隔 | 4 小时（防跨午夜重复计数） |
| 掌握判定 | 听、读分别累计 ≥3 个不同日期独立答对 |
| 提示后答对 | 不计独立掌握 |
| 同日订正 | 不改首次得分，不清除已有多日记录 |
| 每日上限 | 复习 30 题 / 批 10 题；新词 8/4/2 三档 |

> 这套算法是产品的教学护城河，v2.0 **仅改展示层**，不动算法。任何修改需单独评审并补回归。

### 8.4 存储、同步与隐私

| 项 | 方案 |
| :--- | :--- |
| 主存储 | `localStorage`，键名不变（`sparks_learning_v2`），新增字段向后兼容 |
| 降级 | 存储不可用（隐私模式）→ 内存模式 + 图标提示"退出会丢记录" |

## 11. 风险与依赖

| # | 风险 | 等级 | 影响 | 缓解 |
| :-- | :--- | :--- | :--- | :--- |

| R5 | 双模式增加状态复杂度，回归成本上升 | 中 | 交付延期 | 模式层与学习内核解耦；内核零改动 |

| R7 | 儿童隐私合规 | 高 | 法律风险 | 最小化采集；录音不落盘；家长同意；可删除 |
| R8 | 家长过度干预削弱自学能力 | 中 | 长期效果 | 介入计数 + "等 5 秒"提示 + 撤除建议 |
