# 儿童听读与间隔复习更新记录

## 当前实现

- 首页默认八个新词、六个句子、一篇 30–60 词故事，以及最多二十个到期复习项；复习积压减少新词，漏学不清零。
- 十二个生活主题，共四十八个儿童活动。起步故事 30–60 词，十二篇原创进阶故事 103–113 词，每篇四道理解题；起步主题完成后继续安排全词库的单主题词汇课。儿童流程没有单词拼写、键盘填空或作文要求，正式 KET 写作等保留在折叠的家长进阶区。
- 每个单词与题目分别记录听力、阅读成功日期和到期日。同日重复不能推进间隔；提示后的答案不计入独立掌握；两个能力各至少三个成功日期才标记单词掌握。
- 学习当天计划保持固定，未完成活动保存当前位置、已答题目和反馈，退出后可以继续。
- 复习积压时只学四个新词，不会将八词课程误记为完成，次日继续剩余单词。首次接触同时安排听力和阅读，未测试的能力不标为成功；提前重读不能推进复习间隔。完成的练习可重新开始，语音提示一经点击就不再算作独立阅读。
- 全部 1687 词补充官方词性；依据 Cambridge August 2025 词表抽取元数据，处理复数、缩略单位与括号变体。
- 健康、家庭、动物和衣服分类重新整理；餐厅课与健康课不混用。增加时间日历与位置方向，原综合复习中的具体词逐项归类；家庭称呼别名归位后当前 220 节词汇短课按单一主题分组。
- 首课八张照片完整：原四张食物照片，加上逐一生成并实际检查的鸡蛋、奶酪、果汁、水照片。发布清单锁定图片哈希，构建只复制核验过的文件。
