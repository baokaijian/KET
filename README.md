# Sparks · KET 英语探索

简洁、无需登录、适合孩子自主开始的英语学习网站。React / Vite 纯静态应用，可部署到 GitHub Pages。

## 新版体验

- 今天：面向 6 岁孩子的听读计划，轻负荷日安排 8 个新词、6 个句子和 1 篇短故事；复习分为固定的每批最多 10 题、每天最多 30 题，约 20–25 分钟，可分段完成。结合未来七天已知排期，将新词降为 4 或 2 个；高积压时优先重读已学故事。周六故事整合、周日不强制新词。
- 学习天地：12 个儿童生活主题，每主题包含新词、句子、短故事和进阶故事四项活动，共 48 项，不要求拼写或打字。家长进阶区域保留 12 单元系统路线，217 节单主题词汇课覆盖全部 1687 词；另有 24 节语法、12 节听读专项、12 次阶段检查和 3 组照片启蒙课。
- KET 小测：按官方技能结构安排阅读 1–5、听力 1–5、25 词邮件、35 词故事、口语两部分的自编训练；提供 36 题综合理解检查。
- 各单元分别保存写作草稿，12 组写作任务与 36 个口语话题支持自查和本地录音回听。
- 成长记录：听力与阅读分别保存复习状态。每次符合条件的独立答对后，下一次间隔依次为 1、2、4、7、16、30、60、120、180、365 天；答错或使用提示安排次日复习，保留此前的成功日期、暂不计掌握，到期后的独立答对才能恢复。同日订正不能消除复习需求或推进掌握。听力和阅读均至少在三个不同日期独立答对才计为掌握。这些间隔是可调整的教学初值。
- 答错后可以“再试一次”，每题一次，退出或刷新后仍能续做；订正后的答对不改首次得分、不算独立掌握，也不会清空之前数天的学习记录。
- 每日复习最后一题仍可续做订正，即使当天已记录三十次首次作答；看完结果后才切到下一批或结束，不重复计算已答题目。
- 英式/美式朗读选择、慢速与例句朗读。系统 TTS 无法保证每台设备音色一致。
- 手机、平板与桌面布局；页面位置使用 hash，静态部署后刷新不依赖服务端路由。

## 内容边界

**目前不是 1687 词完整图片验收通过版本，也不是正式 KET 模拟考试。**

全部 1687 词条均提供中文常用含义，旧占位释义已清除。`src/data/ket-meanings.js` 保存原创中文释义补全与纠错，保留易混词、多义词和英美用法提示；修正 PDF 提取产生的断词并保留原 ID。中文解释不是从词典批量复制的原文，也不声称涵盖每个词的所有高级含义。

词汇课答对、语法和理解题答对会更新进度及错题；系统课程需要至少 80% 正确率才记为通过，写作自查与客观题通过分开记录。全部词条标注官方词性，名词复数另有说明。重新核对官方主题清单，修正健康、家庭、动物、衣服等分类，增加时间日历与位置方向；救护车等健康词不再进入餐厅课，月份、书包、加油站等不再放进未归类词表。每节词汇课只有一个主题。未核实的音标、模板例句和旧图片仍不展示；109 张已校对照片注明对应词义，如 `book` 的照片只解释“书”而非“预订”。十二个儿童主题的全部 95 个不同词均有专属照片，另有八张健康照片与六张起步词语境照片；家庭、房间、公园、健康、衣物、天气、身体、购物、出行与一天课程的八个词均有照片、短句、中文解释及例句朗读；购物课的 bag 与学校课是同一个词，使用同一张已核验照片；家庭关系和医护角色由教学语境明确，不用人物外貌猜测身份。每日卡片对多义词标明照片对应词义；跑、跳、走分别使用能区分动作的照片。天气词不再归入出行；`cold` 以“天气冷”为教学主主题，保留“感冒”的完整释义。分组内容变化时不继承旧分组的通过标记，未变课程、单词记录和复习日期保留；成长记录仅统计当前课程。

原反馈的 all/also/always/a.m./and/answer 六词分别替换为独立的真实感场景，必须配合双语例句理解，不把功能词当作物品名称。all 显示整组四个孩子均戴帽，also 显示已有苹果又得到香蕉，always 显示七天打勾的放鞋习惯，a.m. 时钟明确为 9:00 AM，and 连接书与杯子，answer 显示算式问题与答案三。`a.m.` 的单词朗读按字母传入 `A M`，不改动普通的 `am`；实际系统音色仍待真机听辨。完整提示词、指定词义、例句及哈希在 `src/data/starter-images.js`，释义核对依据见 `docs/acceptance/content-corrections-2026-10-12.md`。

照片由内置 imagegen 分别生成，最终资产统一放在 `public/word-images/{wordId}.webp`。原十二张照片已按词 ID 迁移，`public/learning-images/` 仅保留原始归档，不进入发布包。`src/data/image-reviews.js`、`src/data/additional-images.js` 及其导入的家庭、房间、公园、健康、衣物、天气、身体、购物、出行与一天清单保存 Codex 实际视觉复核说明与文件哈希；这是代理视觉复核，不是家长签字，也不是系统语音听辨验收。替换图片后哈希测试必须失败，直到重新检查并记录证据。全部 1687 词的生成队列在 `src/data/word-image-plans.js`，已完成补图的提示词记录在 `docs/acceptance/image-generation-log.md`。

词义选择题优先使用本主题的不同含义，常见同义或重叠表达（如 mother / mom、bike / bicycle）不互相作为错误答案。复习与每日新词使用所在课程的词池，不再固定拿全词库开头的无关词做选项。

尚未替换的旧模板图不进入页面或发布包。构建时只把 favicon 和清单中的已核验照片复制到忽略版本控制的 `public/learning-assets/`，再发布到 `dist/`。旧模板生成器已停用，不会再次把生成完成自动标成通过。

复习日期是可调整的教学初始参数，不是艾宾浩斯曲线规定的唯一日程。学习记录与当天计划保存在本浏览器；未完成的活动可退出后继续。旧的“一次答对即掌握”记录保留学习接触信息，但不迁移为长期掌握证据。起步故事为 30–60 词；十二篇原创进阶故事为 103–113 词，支持逐句听读。起步主题结束后，每日计划继续安排进阶故事和全词库中的单主题新词课，不会停在空的早餐计划。

## 本地运行

需要 Node.js 22.12 或更高版本；数据验收中的导入回归还需要 Python 3（不需要安装 PDF 库）。重新抽取官方 PDF 时另需 `pdfplumber`。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。录音需要麦克风权限，线上需要 HTTPS；录音不上传，只在当前页面播放。学习记录和写作草稿保存在当前浏览器，新版使用独立存储键，不覆盖旧版进度。

## 发布到 GitHub Pages

1. 把代码推送到当前仓库默认分支 `main` 或 `master`。
2. 在仓库 Settings → Pages → Build and deployment 中，Source 选择 **GitHub Actions**。
3. `Deploy Sparks to GitHub Pages` 工作流会先跑检查，再构建与发布。

当前仓库是 `baokaijian/KET`，项目站点路径自动设为 `/KET/`，预期地址为 `https://baokaijian.github.io/KET/`。这只是部署目标，配置就绪不代表已经上线。用户名站点仓库 `用户名.github.io` 自动使用根路径 `/`。如使用自定义域名，可在仓库 Actions variables 中设置 `VITE_BASE_PATH=/`，域名仍需自行在 Pages 设置中配置。

本地模拟项目路径：

```sh
VITE_BASE_PATH=/KET/ npm run build
PLAYWRIGHT_PRODUCTION=1 PLAYWRIGHT_BASE_PATH=/KET/ npm run test:e2e
```

也可运行 `npm run test:pages`，它使用独立发布目录 `dist-pages`，检查 `/KET/` 子路径下全部桌面与手机流程，且确认旧模板图没有进入发布包。

配置参考 [Vite 官方 GitHub Pages 指南](https://vite.dev/guide/static-deploy.html#github-pages)。

## 检查与验收

```sh
npm run test:functional
npm run test:acceptance
npm run review:images
```

发布课程的验收包含：代码检查、构建、全词库释义无占位及易混词回归、1687 词课程覆盖、题库答案结构、课程通过阈值、数据和音频逻辑、图片解码及哈希、桌面/手机逐页查词、12 单元语法和理解主路径、听力填空与原题复习、独立写作草稿与自查、照片启蒙回归及录音清理。录音测试不使用真人麦克风录音。自动检查可验证完整性及明确的回归案例，不能替代教师逐词语义审阅。

`npm run test:full-content` 是全词库图片门禁，已接入 `test:acceptance`。总验收当前应失败，图片覆盖为 **109 / 1687**，余下 1578 项 `pending`，不是把它们标为通过来绕过验收。逐词表在 `docs/acceptance/image-review-checklist.md`。`test:functional` 单独验证已实现的功能；本轮全词库更新尚在进行，功能回归通过不能代替图片全量验收。

真实设备仍需家长听辨单词/例句发音与音效，并体验麦克风录制、回放和清理。浏览器自动测试使用语音 mock，只证明传入文本、语言、速率和错误处理正确，不能证明实际声音准确。

官方 PDF 元数据保留原记录，`vocabulary-corrections.js` 单独记录有词典证据的词性纠正，不把来源中的明显错误教给孩子。导入覆盖全部主题附录页，区分 `it` 和 `IT`、括号词义说明与可选短语成分。儿童到期复习排除家长填空题；阅读语音提示随断点保存，错题列表不提前展示中文答案。听力播放没有回调时有超时错误提示，也可暂时跳过；跳过不记录对错，不产生掌握证据。

DeepSeek Harness 已交付独立流程审计及限定范围的复习排期实现，主任务复核并增加批次断点与旧记录回归；固定故事答案位置、跨主题题目 ID、句子词汇覆盖与 44px 触控尺寸也已整改。240 天模拟只能说明特定初始条件下的排期表现，不能证明真实儿童长期负荷合适。Antigravity 内容报告已修订为待复核，剩余语义与标签建议仍需核查；代理完成任务不等于平台验收通过。

## KET 范围

正式 A2 Key 包含阅读与写作、听力和口语；本项目是按其技能结构组织的系统学习课程，不能替代官方样题与教师评估。练习量与呈现不等同于真卷：听力 Part 1 技能先使用文字选项，故事写作用三步情节引导而非正式三图试题，TTS 对话不是双人真人录音。写作只做字数和要点自查，口语只做录音与自评，不给虚假的语法、发音或证书预测分数。

参考 [Cambridge 官方考试结构](https://www.cambridgeenglish.org/exams-and-tests/qualifications/key/format/) 与 [Cambridge Dictionary 的 book 词义和音标](https://dictionary.cambridge.org/us/dictionary/english/book/)。
